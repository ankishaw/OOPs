This repository contains examples of Advanced Object-Oriented Programming (OOP) concepts used in real-world system design and scalable software development.

Topics Covered

1) Interfaces
2) Static Classes & Static Methods
3) SOLID Principles
*Open–Closed Principle
*Dependency Inversion Principle
*Liskov Substitution Principle

4) Class Relationships
*Association
*Aggregation
*Composition
5) Object Cloning (Shallow & Deep Copy)
